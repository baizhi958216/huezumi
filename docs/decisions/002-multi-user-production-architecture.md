# ADR-002：多用户生产数据与任务架构

- 状态：accepted；队列部分被 [ADR-004](004-postgres-queue.md) 取代
- 日期：2026-09-05

## 背景

本地 `.data` 记录和由查询请求触发的供应商轮询无法提供多用户所有权、私密素材、原子额度预留或多实例任务恢复。

## 决策

采用 PostgreSQL 作为帐号、钱包、任务和审计事实源；采用 private OSS 保存输入和输出；采用 Redis/BullMQ 调度独立 worker。任务受理与 outbox 在同一数据库事务完成。队列按至少一次投递设计，数据库唯一约束、条件更新和账本幂等键保证最终效果只发生一次。

## 结果

Web 查询变为只读数据库，浏览器关闭后任务仍会推进。媒体对象默认私有，所有权在平台数据库验证。部署增加 PostgreSQL、Redis、worker和 OSS的运维成本，并要求真实环境执行备份恢复与对象访问验证。

## 回滚

停用新任务受理，保留新版数据库与流水，只读运行可兼容 schema 的应用版本。不得回滚到公开文件入口或用旧数据库快照覆盖切换后产生的账目。
