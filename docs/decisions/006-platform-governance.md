# ADR-006：平台连接、执行身份与作品边界

- 状态：accepted
- 日期：2026-09-18

## 决策

连接身份与不可变连接版本分离，私有凭据由独立环境主密钥以 AES-256-GCM 加密入库。管理员只获得配置状态，不获得保存的凭据。报价固定连接版本，新设置不改写已受理任务。ComfyUI 继续使用独立执行端配置。

runs 为跨模态执行身份，视频状态继续从 generations 派生；文档和不可变版本保存文本结果。works 为作品索引，引用版本或私有媒体资产，与项目关联。作品读取仅查询 PostgreSQL，引擎历史在后台同步并归档。

文本使用连接、模型和篇幅的固定正整数报价，复用钱包、账本和 outbox。未知提交进入人工核对，不自动再调用上游。AI 保存锁定文档并检测基础版本，遇到并发编辑保存独立候选，不覆盖用户内容。

## 后果

新增关联和兼容读取，不改写旧视频请求及历史账目。数据库备份必须与加密主密钥分别保管。轮换连接产生新版本，撤销旧凭据是显式操作。前后端同步迁移 API，保留持久化媒体 URL 与旧队列消息的兼容入口。
