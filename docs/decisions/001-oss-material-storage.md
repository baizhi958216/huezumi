# ADR-001：上传素材使用服务端 OSS 转存

- 状态：accepted
- 日期：2026-09-01
- 决策者：
- 关联规格：`spec/2026-09-01-oss-material-storage.md`

## 背景

远程视频供应商需要通过公网 URL 读取参考素材。当前应用返回本地 Nitro storage 地址，开发机上的 `localhost` 和未暴露的部署地址无法被百炼访问。

## 决策

`POST /api/files` 继续由服务端接收 multipart 文件，并使用服务端 `ali-oss` SDK 将素材上传到阿里云 OSS。OSS 配置完整时响应返回 OSS 公网 URL；AccessKey 只从私有 runtime config 读取。为兼容旧接口和提供短期兜底，服务端仍保留本地元数据与文件副本。

默认对象使用服务端 UUID 作为文件名、`huezumi/uploads` 作为前缀，并使用 `public-read` 对象 ACL，使百炼可以直接读取返回地址。若使用自定义域名或内网上传端点，通过独立的公网基地址配置生成最终 URL。

## 备选方案

- 浏览器直传 OSS：减少服务端带宽，但需要 STS、签名策略、CORS 和前端上传状态管理，超出当前改动范围。
- 仅返回签名 URL：可保持 Bucket 私有，但 URL 有过期时间，且需要处理视频任务执行期间的有效期续签。
- 只保留本地存储：无需新增依赖，但远程供应商仍无法稳定访问素材。

## 后果

### 正面

- 供应商收到的素材 URL 可跨网络访问。
- 浏览器不接触云端密钥。
- OSS 未配置时仍保留原有本地开发能力。

### 负面与风险

- 每次上传产生 OSS 存储和流量成本。
- 当前对象为公开读取，不适合私密素材或多租户生产环境。
- 同时保存本地副本会占用本地磁盘；本次不处理清理和迁移。

## 验证与复审

使用真实测试 Bucket 上传图片、视频和音频，确认 OSS URL 可公开读取并可被百炼任务接受。未来加入账号隔离、私密素材或大文件上传时，复审本决策并优先评估 STS 直传、私有 Bucket 和生命周期清理。
