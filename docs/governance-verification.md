# 平台治理验收记录

本次针对视频、文本和管理员工作流的现有能力进行治理。没有新增普通用户图片生成、分镜编辑、剪辑或成片导出。

## 自动验证

- `pnpm check:full`：文档约束、42 项单元测试、lint、TypeScript 和 Nuxt production build。
- `pnpm test:postgres`：独立随机测试数据库，22 项测试；结束删除测试库，不调用真实供应商。
- `PYTHONDONTWRITEBYTECODE=1 vendor/ComfyUI/.venv/bin/python -m unittest discover -s comfyui/custom_nodes/huezumi_prompt -p 'test_*.py'`：34 项 Python 节点测试。
- `docker build -t huezumi:governance-check .`：应用镜像构建；构建后的镜像可对独立测试数据库执行 `pnpm db:migrate`。
- production Compose 使用脱敏配置解析，核对 Web 不消费队列、worker 使用 `NUXT_WORKER_CONCURRENCY`、ComfyUI 不接收平台加密密钥。

测试覆盖凭据加密与版本隔离、owner 隔离、重复受理、报价过期、余额与预算拒绝、并发上限、未知提交、worker 恢复、结算幂等、并发保存及 AI 不覆盖手动编辑。分页包含同一毫秒内不同数据库微秒的边界，摘要不含正文。工作流覆盖提交前登记、未知提交不重发、重复输出、归档失败与历史失效后重试；流式归档覆盖大小上限、超时取消和临时文件清理。

配置导入与数据回填各执行两次，验证连接版本、主密钥和账目不重复变化。配置检查及非法 JSON 导入使用脱敏 fixture，验证错误不输出凭据。dotenv JSON 的序列化额外执行往返校验。

## HTTP 与页面检查

使用独立数据库、测试管理员/普通用户和本地模拟文本接口，未消耗真实供应商额度。

- HTTP 检查认证、管理员权限、owner 文档隔离、统一错误码与请求 ID、敏感字段不返回，以及作品与概览统计一致。
- 页面检查文本空态、固定报价确认、后台生成、保存及结算、手动新版本、未保存编辑的离页保护，以及任务链接恢复时保留当前最新手工版本。
- 作品库检查文档摘要、项目关联和继续生成视频；视频页验证固定来源版本与可编辑片段，以及没有视频连接时的禁用状态。
- 管理页检查连接摘要、编辑时密钥保持空白、历史版本和部署状态展示。
- 390×844 移动视口检查作品库和视频来源区域；保留现有视觉体系。

## 本机迁移与上线限制

本机已先生成权限为 `0600` 的数据库与环境配置备份，再执行增量迁移、连接导入和历史回填。`.env` 的业务配置已移入数据库，私有部署配置按用途分组；备份已被 Git 和 Docker 排除。原环境导入了 2 个视频连接，没有可导入的文本连接；文本连接和篇幅价格需管理员在 `/admin/settings` 配置，没有预设商业价格。

本地通过不代表生产上线验收。真实供应商连通性与账单核对、目标 GPU 上 ComfyUI 的构建/运行和模型权重、生产私有存储网络、备份恢复演练仍应在部署环境确认。维护窗口内执行匹配的 Web/worker 切换；故障时把新请求预算设为 0，保留读取、归档和结算，不能回滚数据库快照覆盖新账目。
