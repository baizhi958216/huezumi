# 工作流输出图片比例与弹窗预览

- 状态：completed
- 负责人：Codex
- 创建日期：2026-09-08
- 相关 issue / ADR：无

## 背景与问题

工作流右侧输出区把图片固定在正方形容器内，并使用 `object-fit: cover`，横图和竖图都会被裁剪。点击图片当前会直接打开新标签页，无法留在工作流内查看大图。

## 目标

- 输出图片按原始宽高比完整显示，单张图片充分使用输出区宽度。
- 点击图片打开页面内的大图预览，图片完整缩放到可用视口内。

## 非目标

- 图片编辑、缩放拖拽、批量下载或前后切图。
- 修改视频预览、生成执行链路、输出文件契约或访问权限。

## 用户流程

1. 工作流产生图片后，用户在输出区看到保留原始比例的缩略图。
2. 点击缩略图或通过键盘激活，弹窗展示对应图片与文件名。
3. 图片加载时显示提示；加载失败时显示错误与原图访问入口。
4. 点击关闭按钮、遮罩或按 Escape 关闭弹窗，焦点回到缩略图。

## 行为契约

- 图片仍通过 `buildViewUrl` 生成的 `/api/comfyui/view` 地址读取，不引入新接口或复制文件。
- 多张图片分别保留各自比例；输出为空时保留现有空态。
- 弹窗限制在当前视口内，图片等比缩放、不裁剪；长文件名不能撑破布局。
- 预览状态属于对应图片组件；输出移除时弹窗一起销毁。
- 复用 Nuxt UI 弹窗的语义、焦点管理和关闭行为，触发按钮提供可读名称。

## 验收条件

- [x] 横图、竖图、方图及混合输出完整显示，单张图片不再只占一列。
- [x] 点击任意图片打开对应大图；关闭按钮、遮罩和 Escape 均可关闭，键盘焦点正确恢复。
- [x] 无输出、图片加载中及读取失败时均有明确反馈。
- [x] 桌面与窄屏下图片和弹窗不溢出视口，长文件名不撑破布局。
- [x] 视频保留原有入口和显示方式，输出文件类型及 API 不变。
- [x] `pnpm check` 通过，并完成页面交互与布局检查。

## 边界情况

- 极宽或极高的图片、长文件名、多张不同宽高比图片。
- 图片请求失败、重复打开、预览期间输出列表被清空或替换。

## 实现提示

复用现有输出网格与 Nuxt UI `UModal`，不新增依赖。

## 验证计划

- 自动化检查：`pnpm check`。
- 人工检查：使用不含用户素材的图片 fixture 检查比例、加载、空态、失败、键盘交互和响应式布局。
- 需要凭据或外部环境的检查：本次不修改生成协议，不要求重新调用模型供应商。

## 上线与回滚

纯前端改动，无配置或数据库迁移；回滚组件与样式即可恢复旧行为。

## 实现结果

新增 `WorkflowOutputImage.vue`，封装原比例缩略图、加载/失败提示和 Nuxt UI 弹窗。输出网格使用自动填充有效列并按顶部对齐，单图使用完整列宽；视频仍保留原有链接与方形媒体容器。缓存图片在挂载时检查加载结果，避免错过加载事件而停留在占位状态。

浏览器验证使用仓库外的临时 Nuxt 页面挂载实际工作流检查器、图片组件与项目样式，图片请求由无凭据 fixture 提供。已检查 1280×720 与 390×844 视口、728×1024 竖图、1200×675 横图、800×800 方图、混合输出、1:10 / 10:1 极端比例、长文件名、延迟加载、404、空输出、三种关闭方式和焦点恢复。预览期间清空输出后弹窗消失，页面恢复正常交互。`pnpm check` 包含的 19 项单元测试、lint、类型检查及仓库约束通过。

未重新调用真实模型生成，未改动工作流/API 权限、文件读取或任务执行链路。临时验证页与素材不进入仓库。
