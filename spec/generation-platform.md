# 统一视频生成平台基线

- 状态：completed
- 创建日期：2026-09-01
- 相关设计：`DESIGN.md`

## 目标

平台用统一请求支持文字、首尾帧与多模态参考生成，并可在不改写核心 UI 和存储结构的前提下接入多个视频供应商。

## 核心契约

- 客户端从 `/api/providers` 获取运行时已启用的供应商及能力。
- 创建任务必须同时通过通用 schema 和供应商能力校验。
- 平台状态统一为 `PENDING`、`RUNNING`、`SUCCEEDED`、`FAILED`、`UNKNOWN`。
- 任务创建后先保存供应商 task ID，再通过列表或详情查询刷新状态。
- 首尾帧与 `reference_*` 素材不能在一个请求中混用；尾帧必须配合首帧。
- 本地上传返回供应商可访问的绝对 URL。

## API 验收条件

- [x] `GET /api/providers` 不向客户端返回密钥，并反映凭据是否配置。
- [x] `POST /api/generations` 对非法结构返回 422，对不存在供应商返回 400，对缺失凭据返回 503。
- [x] 创建成功返回含平台 ID、供应商 task ID 和时间戳的记录。
- [x] `GET /api/generations` 按创建时间倒序返回，并刷新进行中任务。
- [x] `GET /api/generations/:id` 对不存在记录返回 404，并仅刷新进行中任务。
- [x] 文件上传拒绝缺失文件和超过限制的文件，读取不存在素材返回 404。

## 当前非目标

- 用户账号、权限和项目隔离。
- 分布式队列、多实例一致性和供应商 webhook。
- 计费、配额、内容审核和素材生命周期管理。
- 私有对象签名 URL、对象生命周期清理和后台归档 worker。
