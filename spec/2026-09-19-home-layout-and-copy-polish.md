# 首页布局重塑与文案去 AI 味

- 状态：completed
- 创建日期：2026-09-19
- 负责人：Antigravity

## 背景与问题

首页此前版本虽然确立了暖色调品牌色彩，但存在两个明显痛点：

1. **文案 AI 味过重**：充斥着大量虚无空洞的 AI 鸡汤模板句（如“每个小小的灵感”、“给主角一点小脾气”、“捡起一颗灵感”等），缺乏真实影视动漫创作者需要的力量感、镜头感和专业工具质感。
2. **版面布局略显粗糙怪异**：使用了不协调的椭圆蛋形切图、墓碑拱形截角、歪斜贴纸和旋转符号，去卡片化后显得空洞松散，缺少视觉锚点与精致感。

## 目标

- 重构全站首页文案：告别幼态和 AI 模板腔，采用专业、有力、富有分镜感与创作者共鸣的语言体系。
- 升级现代开放式视觉布局（去卡片化）：彻底废弃通篇套用卡片容器的模板化做法，采用开放式四栏建筑排版（Editorial Spread）、大画幅艺术展陈画廊（Cinema Exhibition）、开放式工作台技术规格展面（Open Spec Sheet）与全宽沉浸终局，营造真正具备高级平面设计与电影画册质感的视觉体验。
- 保留所有底层契约：保留 `/studio`、`/studio/video`、`/projects` 等路由跳转，保留 `/api/providers` 动态模型驱动与管理员专属图像工作流说明，保持浅色/深色主题无缝适配。

## 非目标

- 不修改后端 API、生成契约、计费逻辑与数据库结构。
- 不引入外部重型 UI 库或破坏现有的 Tailwind v4 / Nuxt UI 体系。

## 验收条件

- [x] 首页各模块文案完全去除空洞 AI 模板套话，展现分镜剧本、角色设定、高质感视频渲染等核心价值。
- [x] 全面去除千篇一律的卡片组件堆砌，开放式排版节奏通透、留白自然。
- [x] 灵感切换、模型目录切换、复制模型 ID、FAQ 折叠交互均正常可用。
- [x] 移动端 375px/390px 窄屏无横向滚动溢出，深色主题对比清晰。
- [x] `pnpm check` 与测试全部通过。

## 验证与实现结果

- 彻底解构通篇卡片组件：Hero 灵感区升级为开放式导演指令台；四大支柱改为开放式四栏建筑排版（Editorial Spread）；画廊展陈直接呈现大画幅图注；模型矩阵重构为开放式双栏规格展面；底部 CTA 重构为全宽沉浸式终局。
- 首页文案系统性更新为影视级专业表达。
- 执行 `pnpm check` 与 `pnpm test`（54 个测试全部通过），无报错无回归。
