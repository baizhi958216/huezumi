# 全站导航统一

- 状态：accepted
- 负责人：
- 创建日期：2026-09-08
- 相关 issue / ADR：

## 背景与问题

当前普通页面、创作台和工作流分别使用三套顶栏。品牌尺寸、导航入口、当前页状态、主题与帐号入口以及移动端折叠方式都不一致，页面跳转时会出现明显的高度与视觉语言变化。工作流工具栏还重复承担了全站导航职责，导致权限入口缺失并挤占页面操作空间。

## 目标

- 所有顶层页面始终展示同一套全站头部、品牌、权限入口与当前页状态。
- 桌面和移动端使用同一个导航事实源，角色变化不会产生入口差异。
- 创作台与工作流只保留页面专属功能，不再复制全站导航。
- 固定头部、页面正文、工作区高度和 sticky 控件共享一个顶部偏移。

## 非目标

- 不重做首页营销内容、生成表单、作品卡片或工作流画布。
- 不改变页面权限、认证流程、API、存储或供应商契约。
- 不引入新的 UI 或动画依赖。

## 用户流程

1. 访客从首页、创作台或作品库进入任意公开页面，顶栏的品牌、入口和操作位置保持稳定。
2. 登录用户可从同一顶栏进入我的空间；管理员额外看到工作流和控制面板。
3. 窄屏下顶级入口折叠到菜单，主题、帐号和菜单按钮仍可直接访问。
4. 进入工作流后，全站头部保持不变，工作流名称、服务状态、保存和运行留在独立工具栏。

## 行为契约

- 顶级导航由单一配置生成：创作台、作品库始终可见；我的空间仅登录后可见；工作流和控制面板仅管理员可见。
- 当前路由同时驱动桌面与移动导航的选中状态，并用 `aria-current="page"` 暴露给辅助技术。
- 品牌链接、主题、帐号与移动菜单在所有顶层页面保持同一顺序和交互语义。
- 页面正文不得被固定头部遮挡；创作台、工作流和作品库 sticky 工具条使用同一个顶部偏移变量。
- 工作流工具栏不得再包含品牌、全站路由或主题切换。

## 验收条件

- [ ] Given 任一公开顶层页面，When 在首页、创作台和作品库之间跳转，Then 顶栏高度、品牌、入口顺序和交互样式保持一致。
- [ ] Given 登录用户或管理员，When 会话状态加载完成，Then 角色对应的导航入口同时出现在桌面导航与移动菜单中。
- [ ] Given 当前位于一个顶层入口，Then 对应链接显示统一选中态并带有 `aria-current="page"`。
- [ ] Given 390x844 窄屏，Then 顶级入口折叠到菜单，头部不横向溢出且正文不被遮挡。
- [ ] Given 1440x900 桌面，Then 导航、主题、帐号与首页主动作不重叠，工作区可用高度正确。
- [ ] Given 工作流页面，Then 页面工具栏只展示工作流上下文与命令，画布、服务状态、保存和运行行为不变。
- [ ] Given 键盘或减少动态效果偏好，Then 导航具有可见焦点且不依赖滚动位移或尺寸动画表达状态。
- [ ] Given 浅色或深色主题，Then 顶栏、选中态与分隔线保持可辨识。

## 边界情况

- 会话尚未加载时先显示公开入口，加载完成后再补充对应角色入口。
- 页面存在较长工作流名称或较多管理员入口时，桌面导航在断点前折叠，不裁切文本。
- 工作流服务处于安装、启动、运行或错误状态时，仅页面工具栏变化，全站头部不改变尺寸。

## 实现提示

- 将导航项和路由匹配提取为纯函数，桌面链接和移动菜单共用。
- 用 CSS 自定义属性维护全局头部高度和正文偏移，不在页面中继续复制像素值。
- 工作流的低频文件操作可以收进更多菜单，为名称、状态和运行操作留出稳定空间。

## 验证计划

- 自动化检查：导航配置纯函数测试、`pnpm check`、`pnpm check:full`。
- 人工检查：桌面 1440x900 与移动 390x844 下检查首页、创作台、作品库和可访问的认证页面；抽查浅色、深色、键盘焦点与菜单。
- 需要凭据或外部环境的检查：管理员工作流完整页面需要管理员会话；没有 ComfyUI 时只验证页面壳与服务错误态。

## 上线与回滚

无配置、数据迁移或部署顺序变化。回滚前端组件、布局和样式即可恢复旧顶栏。
