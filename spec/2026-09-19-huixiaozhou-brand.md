# 绘小宙品牌与全站视觉

- 状态：completed
- 负责人：Codex
- 创建日期：2026-09-19
- 相关 issue / ADR：无

## 背景与问题

项目更名为「绘小宙」，面向故事、角色、画面与视频创作者。原首页以工业化视频管线为主，技术术语与冷硬视觉不符合轻快、可爱、二次元的小宇宙定位。

## 目标

- 统一品牌为「绘小宙」，主张「创作属于自己的小宇宙」。
- 奶油白、蜜桃粉、珊瑚红为主，鹅黄、嫩绿辅助；不使用蓝紫色品牌视觉。
- 首页、导航、创作台、作品库、账户和管理页共享暖色令牌、圆角与清晰的交互反馈。

## 非目标

- 不变更生成 API、计费、存储前缀、包标识、数据库、权限或路由。
- 不新增独立角色生成能力，不将管理员图像工作流宣传为普通用户已开放能力。

## 用户流程

1. 首页认识品牌，通过故事、角色设定、画面与视频了解创作方向。
2. 故事与角色设定进入已有文案剧本；视频进入已有视频创作；管理员可进入图像工作流。
3. 导航与作品库延续相同品牌，保留登录、错误、空态和主题切换。

## 行为契约

- 首屏插画、示例设定标注为创意示意，不伪装成用户作品或实时运行结果。
- 模型信息以现有能力目录为准，不伪造数量、性能评分或生成进度。
- 所有旧链接和工程标识继续兼容；仅更改用户可见品牌及视觉。

## 验收条件

- [x] 品牌、登录弹窗、站点元数据、favicon 一致。
- [x] 四类创作说明可访问，管理员工作流权限提示明确。
- [x] 桌面与窄屏无横向溢出，浅深主题和键盘焦点可辨识。
- [x] 模型空态和失败态可理解，现有编辑和生成行为保留。
- [x] pnpm check:full 通过，页面人工验证结果记录于实现结果。

## 边界情况

- 模型目录为空或加载失败时仍允许进入创作台。
- 未登录、普通用户与管理员保持原有权限。
- 深色主题使用暖棕底色，减少动态效果时禁用装饰位移。

## 验证计划

自动检查 pnpm check:full；人工检查首页、创作台、作品库、登录及移动布局。真实生成不在本次视觉验证范围。

## 上线与回滚

无需迁移。回滚品牌资源、页面和样式即可，保留用户数据与工程标识。

## 实现结果

已统一品牌标识、favicon、SEO、首页六个模块、登录和创作空态，并更新全站颜色、圆角、组件语义色及账户/后台残留的蓝紫色强调。插画及完整提示词见 `docs/brand-art.md`。

人工验证：1440×900 桌面与 390×844 手机首页宽度与滚动宽度一致；浅色/深色、灵感切换、视频链接、模型切换、登录弹窗、创作台和作品库未登录/空态均可用。浏览器无 error 级日志。模型加载/空/失败分支经代码检查，未模拟网络失败；管理员页面仅验证共享令牌与源码，未登录进行端到端测试。没有提交付费生成。
