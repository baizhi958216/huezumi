# 工作流视频进入作品库

- 状态：completed
- 负责人：
- 创建日期：2026-09-16
- 相关 issue / ADR：[百炼视频工作流](2026-09-16-bailian-wan3-comfy-workflow.md)

## 背景与问题

管理员的百炼工作流已成功生成视频，执行 ID 写在 `comfy_executions`，MP4 留在 ComfyUI output，工作流右侧可以预览；作品库却只读取 `generations`，因此这次作品不在那里。

## 目标

- 作品库列出当前管理员自己成功生成的工作流视频，包括已有执行。
- 在作品库直接播放，并可打开原视频；刷新页面后仍能从执行记录找回。
- 作品库同时保留原平台供应商任务，不混淆其报价、额度和归档状态。

## 非目标

- 不把 ComfyUI 原始图或百炼原始请求塞进平台 `GenerationRecord`。
- 本次不转存 ComfyUI output 到 OSS，不改变工作流收费或任务提交。
- 普通用户仍不可执行或读取共享 ComfyUI 工作流。

## 用户流程

管理员进入作品库，在“工作流视频”区找到已完成作品，点开卡片播放；平台供应商作品继续在原区域显示。若 ComfyUI 当前不可用，页面明确提示工作流作品暂时无法加载。

## 行为契约

作品库 API 只读取当前 owner 的 `comfy_executions`，从对应 ComfyUI 历史提取成功且带受管 output 视频的记录，归一化为独立 `WorkflowProjectRecord`。视频 URL 经现有管理员鉴权代理访问，不能把任意文件名或其他 owner 的历史泄漏给普通用户。生成节点和显式输出节点登记同一文件时只展示一次。历史未完成、失败或不含视频的执行不作为视频作品展示。

## 验收条件

- [x] Given 已完成的百炼执行，When 管理员进入作品库，Then 能看见本次视频并直接播放。
- [x] Given 生成节点和输出节点登记同一个文件，When 列表归一化，Then 作品只出现一次。
- [x] Given 他人或普通用户，When 查询工作流作品，Then 不返回该管理员的输出。按 owner 查询；普通用户返回空列表；未登录请求返回 401。
- [x] Given ComfyUI 不可用，When 进入作品库，Then 平台作品仍正常显示，工作流区域说明加载失败。工作流请求错误独立处理；未停止真实 ComfyUI 服务验证。
- [x] Given 作品库筛选、搜索和刷新，When 操作，Then 工作流作品与平台作品的计数和可见结果一致。
- [x] `pnpm check:full`、主要成功与失败路径验证及页面人工检查通过。

## 边界情况

ComfyUI 历史和 output 卷决定此处工作流视频的可用性；历史或文件被清理后无法从本列表恢复，不自动提交新的收费任务。持久 OSS 归档需另行设计。

## 验证计划

- 单元测试：历史归一化、去重、非法文件、owner 范围。
- 本地 API 和页面：已有百炼执行可见、视频预览、空态和错误态。

## 上线与回滚

仅增加查询与页面展示，不改变数据库格式或旧执行；移除作品库工作流区域即可回滚。

## 实现结果

新增管理员所属工作流执行的作品库查询，按 ComfyUI 历史归一化视频文件，重复登记只产生一条作品。作品库独立展示带原生播放控件的工作流视频，保留原平台生成卡片、筛选和统计。本机管理员页面已看到这次百炼视频，点击播放后画面前进并出现暂停控件；刷新和已归档筛选正常，手机宽度布局已检查。未登录 API 返回 401；`pnpm check:full` 五项通过，单元测试覆盖成功、去重、未完成、失败及无效文件。视频仍依赖 ComfyUI 历史和 output 卷，未做 OSS 长期归档。
