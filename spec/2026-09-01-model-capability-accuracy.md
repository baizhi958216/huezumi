# 模型级能力准确性

- 状态：completed
- 创建日期：2026-09-01
- 相关设计：`DESIGN.md`

## 背景与问题

现有能力目录只在供应商层声明生成方式、分辨率、时长与音频能力，同一供应商下的所有模型因此共享一套选项。实际上这些限制通常由“模型 + 生成方式 + 分辨率”共同决定，导致首页可能把部分模型能力描述成全平台能力，创作台也可能组合出上游不接受的请求。

## 目标

- 首页明确展示平台已接入的 API 模型，而不是供应商完整产品线。
- 模型名称、用途和供应商级摘要与 2026-09-01 可访问的官方 API 文档一致。
- 创作台切换模型后，只展示该模型支持的生成方式、素材、分辨率、画幅、时长和音频能力。
- 服务端使用同一份模型级约束拒绝无效组合。

## 非目标

- 自动同步供应商模型目录。
- 接入供应商的全部历史模型，或把厂商模型总数等同于平台已适配数量。
- 补齐当前 UI 尚未支持的批量参考素材、视频编辑、视频延长和百炼文件/网页输入。
- 使用真实凭据产生计费任务。

## 用户流程

1. 用户在首页看到平台当前已接入的全部 API 模型，并可逐一查看能力范围；首页不展示供应商层级。
2. 用户进入创作台并选择供应商、模型。
3. 表单根据选中模型收敛可选参数；切换模型时无效的已有选择自动回落到合法值。
4. 绕过前端提交无效模型或参数组合时，API 返回可操作的 422 错误。

## 行为契约

- `ProviderCapability` 继续表达供应商在平台中的能力并集。
- `ModelSpec.capabilities` 可覆盖生成方式、素材、分辨率、画幅、时长和音频支持。
- `durationByResolution` 表达 MiniMax 等模型的分辨率/时长组合限制。
- 未声明模型级覆盖时保持现有供应商级行为，兼容旧目录项。
- 已持久化的 `GenerationRecord` 格式不变。

## 验收条件

- [x] 首页将模型数量称为“已接入 API 模型”，并说明 24 个 model ID 不代表厂商完整产品线。
- [x] 首页通过一个全量模型选择器逐模型展示生成方式、分辨率、时长、画幅和音频，不展示供应商 Tab，也不使用供应商能力并集制造不存在的参数组合。
- [x] 百炼 Wan 3.0 显示两个 All-in-One 模型，参数为 480P/720P/1080P、2–30 秒或智能时长。
- [x] MiniMax 2.3/2.3 Fast/02 在 768P 下可选 6/10 秒，在 1080P 下仅可选 6 秒；2.3 Fast 仅支持首帧图生，只有 02 支持严格首尾帧。
- [x] 可灵只有 V2.6 显示同步音频，且适配器实际发送声音开关。
- [x] Seedance 1.5 Pro 显示 4–12 秒或智能时长并支持音频；1.0 Pro/Fast 显示 2–12 秒且不显示音频或智能时长。
- [x] Seedance 2.0 标准版显示 480P–4K、4–15 秒；2.0 Fast/Mini 仅 480P/720P、4–15 秒；2.5 显示 480P–1080P、4–30 秒且明确不支持 4K。
- [x] 百炼显示 12 个已适配 model ID，并明确官方目录还包含尚未映射的 PixVerse、Vidu 和人像驱动。
- [x] 服务端拒绝目录外模型及模型级不支持的模式、素材、分辨率、时长和音频组合。
- [x] `pnpm check:full` 通过；首页模型目录使用响应式全量选择器与单模型详情，长 model ID 与能力值允许断行，不产生固定宽度横向溢出。

## 边界情况

- 模型切换后当前分辨率对应的时长档位发生变化时，时长自动回落到第一个合法档位。
- 请求省略模型时沿用供应商默认模型及供应商级能力。
- 供应商新增模型但没有填写模型级覆盖时，显式继承供应商级能力。

## 验证计划

- 自动化检查：`pnpm check:full`。
- 人工检查：首页模型目录逐一选择跨供应商模型；创作台逐一切换四家供应商及其模型。
- 需要凭据或外部环境的检查：真实上游提交不在本次验证范围。

## 上线与回滚

无存储迁移或新环境变量。可按文件回滚共享类型、目录、校验与页面改动。

## 实现结果

- 首页能力区改为不展示供应商层级的全量模型选择器与单模型详情，避免供应商并集误导和 24 份规格同时铺开；全局最高输出同步为 4K。
- 能力目录按 2026-09-01 官方文档校正百炼 12、MiniMax 3、可灵 2、Seedance 7 个 model ID。
- Seedance 适配器补齐 `reference_video` / `reference_audio` 的方舟 content 映射。
- API schema 补齐 `2K` / `4K`，能力目录允许的高分辨率可实际通过平台边界校验。
