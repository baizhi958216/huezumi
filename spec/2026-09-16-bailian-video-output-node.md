# 百炼工作流显式视频输出节点

- 状态：completed
- 负责人：
- 创建日期：2026-09-16
- 相关 issue / ADR：[百炼 Wan 3.0 工作流](2026-09-16-bailian-wan3-comfy-workflow.md)

## 背景与问题

已发布的百炼预设只有三个参考素材节点和一个视频生成节点。生成节点内部把视频写入 ComfyUI 输出历史，但画布上没有可见的输出节点，用户无法从连线直观看出生成结果在哪里预览。

## 目标

- 在内置预设中增加“视频输出 / 预览”节点，连接百炼生成节点的结果。
- 生成成功后，右侧输出区显示可播放的视频，不重复展示同一文件。
- 已保存的旧四节点副本保持可运行和可预览。

## 非目标

- 不改变百炼请求参数、任务轮询、收费行为或密钥配置。
- 不执行真实收费生成验证。

## 用户流程

管理员载入五节点预设；生成节点输出接入“视频输出 / 预览”。运行成功后，输出文件在右侧视频卡片中可播放，并可打开原文件。

## 行为契约

- 生成节点输出 ComfyUI output 目录内的 MP4 文件名；输出节点只接受该类型，校验文件归属和存在性，并向 ComfyUI 历史登记视频。
- 生成节点继续登记视频，以兼容此前保存的四节点图。右侧输出区对相同文件只显示一次。
- 删除显式输出节点的旧图仍可执行；显式输出节点不发起第二次百炼请求，也不复制视频文件。

## 验收条件

- [x] Given 新预设，When 载入画布，Then 看到五个节点和生成→输出连线，输出节点显示为独立节点。
- [x] Given 成功任务，When 输出节点执行，Then 右侧出现一个可播放的视频预览。Python mock 验证视频登记，前端输出区使用原生视频控件；未执行真实收费生成。
- [x] Given 已保存旧四节点图，When 载入并执行，Then 生成节点仍登记视频输出。
- [x] Given 输出文件名无效或文件缺失，When 输出节点执行，Then 显示可操作错误，且不读取其他目录文件。
- [x] `pnpm check:full`、Python mock 和运行期节点定义序列化通过。

## 边界情况

预览文件由 ComfyUI output 目录持有；若文件在执行历史仍保留时被清理，预览会加载失败。再次点击运行会创建新收费任务。

## 验证计划

- Python mock：生成→输出文件路径、旧图兼容、非法文件。
- TypeScript：五节点预设、连线与输出去重。
- 本机画布：节点显示、右侧空态、运行期序列化。真实生成需明确付费执行。

## 上线与回滚

部署项目节点包并重启 ComfyUI；内置 JSON 自动重新读取，无数据库迁移。已保存图继续使用原节点定义。

## 实现结果

内置公开预设增加独立视频输出节点，与生成节点通过视频类型端口连接。生成节点保留历史视频登记，兼容旧四节点图；输出节点校验并登记同一 MP4，右侧输出区按文件去重，展示带播放控件的视频和原文件入口。本机画布已确认五个节点、四条连线及输出空态；`pnpm check:full` 通过，Python mock 七项通过，实时节点定义与图序列化无问题。真实收费生成和实际视频播放未执行。
