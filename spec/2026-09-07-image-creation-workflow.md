# 单一图片创作工作流

- 状态：accepted
- 负责人：Codex
- 创建日期：2026-09-07
- 相关 issue / ADR：替代 2026-09-06-comfyui-llm-image-workflow 的内置模板与专属 UI 方案

## 背景与问题

用户不满意两个 Anima 大模型模板，要求只保留一张工作流，单张/多张图片输入、独立需求、大模型、正负提示词、整合、生成分别由节点承担。当前需求控件禁止连线，提示词逻辑固定 Anima，主画布有节点名称专用分支，旧编辑模板没有遮罩。

## 目标

- 用一张十节点模板完成文字/参考图生图、整图编辑、遮罩局部重绘。
- 大模型可由用户在工作流副本中填写云端或本地兼容端点；生图模型通过标准 MODEL/CLIP/VAE 输入替换。
- 业务逻辑留在 ComfyUI 节点包，画布按节点元数据展示上传控件和文本执行结果。

## 非目标

- 视频、音频、聊天历史、自动下载模型、任意模型架构自动适配。
- 多参考图直接进入扩散模型的身份/构图控制，云端图片生成 API、新增平台任务或计费契约。
- 平台内绘制遮罩编辑器；本次上传与原图同尺寸的黑白遮罩。

## 用户流程

1. 从公开工作流载入“图片创作 · 生图 / 原图编辑 / 局部重绘”。
2. 图片节点可留空、上传一张或多张，按槽位排列。需求节点描述素材角色与修改要求。
3. 在大模型连接节点填写自己的兼容端点、API Key、模型和视觉能力，再连到大模型节点；也可选择执行端连接或 manual。
4. 正负提示词各有独立节点，可追加或替换文本；执行结果可查看。
5. 创作设置选择生图/原图编辑/局部重绘；编辑选择原图序号与强度，局部重绘上传同尺寸黑白遮罩（白改黑留）。
6. 选择本机 checkpoint，调节采样种子、步数、CFG；运行并保存图片。

## 行为契约

- 每个图片集合最多八个上传槽，可串联；连线图片优先于同槽文件，按实际非空素材顺序编号。不支持动画图片。
- 生图允许零参考图；编辑必须有有效原图序号；重绘必须有非空同尺寸遮罩。编辑保留原图尺寸，不受生图宽高影响。
- 局部重绘使用 latent noise mask，并在像素空间合成回原图；黑色区域保持原像素。整图编辑不承诺人物完全一致。
- 提示词与生图模型解耦；默认规则描述通用图片提示词，目标模型说明可编辑。普通运行复用成功提示词，刷新序号或素材内容变化使缓存失效。
- 默认模板使用标准 checkpoint 加载器，支持兼容标准文本条件和采样链路的 SD1.5/SDXL 模型；可用配套 loader 替换 MODEL/CLIP/VAE。特殊架构需其自身节点，不宣称任意模型无缝兼容。
- 大模型支持执行端环境连接，也支持在工作流副本的连接节点中填写用户自己的 OpenAI 兼容端点、API Key、模型和视觉能力。带 API Key 的工作流只能保存为私有；导出或转交工作流前必须由用户自行确认密钥风险。
- 删除两个旧内置 JSON，但不删除用户数据库中保存的工作流，保留旧节点名、控件顺序与正负输出协议兼容。

## 验收条件

- [ ] 唯一新模板连线、控件、序列化通过校验，两个指定旧模板移除。
- [ ] 图片空/单/多输入、同名文件替换缓存、异常素材与数量限制有覆盖。
- [ ] 需求连线、模型中立规则、manual、免鉴权本地端点、结构化响应与失败路径有覆盖。
- [ ] 生图/原图编辑/局部重绘覆盖成功和缺图、空遮罩、尺寸不符；黑色区域不变。
- [ ] 通用上传控件支持选择任意图片槽并批量填空槽；文本执行输出不依赖节点类名。
- [ ] pnpm check:full 通过；实际可用模型执行验收或明确记录环境限制。

## 边界情况

空提示词、非图片、动画、多张不同尺寸参考图、越界原图序号、超限素材、遮罩黑白全空、LLM 超时/非 JSON/缺字段、模型缺失、不兼容 VAE。

## 验证计划

- Python unittest：节点和 mock LLM、图像/遮罩算法；使用已有 ComfyUI Python 运行，不增加依赖。
- Vitest：模板 API 序列化与通用控件行为；pnpm check:full。
- 本机可用模型：小尺寸实际生图、编辑、局部重绘；真实外部 LLM 调用仅在已有可用配置时验证。
- 页面：加载、空、错误、响应式布局和多槽上传。

## 上线与回滚

更新节点包后重启 ComfyUI、刷新节点定义。无数据库迁移；恢复旧模板及节点代码可回滚，新保存图在旧节点环境下会提示缺失节点。

## 实现结果

已增加 `ForkVdoLLMConfig` 工作流节点。用户可在工作流副本中填写 `base_url`、`api_key`、`model_name`、`supports_vision` 和超时，并将输出连接到 `ForkVdoPrompt.llm_config`；连接配置优先于执行端环境连接。带 Key 的工作流保存为公开工作流时由服务端拒绝。

限制：接口仍要求 OpenAI Chat Completions 兼容协议；API Key 会保存在私有工作流 JSON 中，导出 JSON 时也会包含它。真实供应商调用和 GPU 生成仍需在目标执行端单独验收。
