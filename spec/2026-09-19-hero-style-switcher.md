# 首屏多风格插画切换

- 状态：completed
- 负责人：Codex
- 创建日期：2026-09-19

## 背景与目标

用户希望用 imagegen 新增不同风格首屏插画，图片可切换，贴签文案与位置同步变化。保留二次元原图，新增毛毡微缩、水彩绘本、立体纸雕三张 AI 概念图。

## 非目标

不增加用户生成能力、不调用供应商 API、不自动轮播，不修改下方创作方向选择。

## 用户流程与行为契约

默认二次元；点击画框下的风格按钮切换图片、替代文字、贴签和位置。按钮支持键盘并暴露选中状态。画框尺寸固定，加载失败提供重新加载按钮，风格选择仍可使用。装饰文案不冒充系统数据，图像明确为 AI 概念插画。

## 验收条件

- [x] 四种风格均可显示，贴签随之变化，标签不遮住人物脸部。
- [x] 390px 与桌面、浅深色可用，画框不跳动，减少动态偏好受尊重。
- [x] 图片载入中与失败提示清晰，切换按钮可继续使用。
- [x] pnpm check 通过，图片资源与生成提示词保存到仓库。

## 边界与验证

按钮为手动切换，不抢焦点；快速切换通过 key 隔离旧图加载事件。浏览器检查四种图、键盘、移动端和主要状态。资源采用 WebP 压缩，保留工具原图。

## 上线与回滚

纯前端与静态资源，无迁移。回滚组件、样式与新增资源即可。

## 实现结果

已用内置 imagegen 生成三张新图并以 WebP 保存（165–417 KB），提示词见 docs/brand-art.md。浏览器确认四种图片切换、文案更新、键盘 Enter、390px 浅深色与加载提示。窄屏文档宽度 390px；二次元与纸雕画框高度均为 338.77px，无尺寸跳动。失败重试分支已实现并经代码检查，未在浏览器模拟资源失败。pnpm check 通过（54 测试通过、22 跳过，lint 与类型检查通过）。
