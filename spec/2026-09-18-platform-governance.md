# 平台契约、配置与创作资产治理

- 状态：completed
- 负责人：Codex
- 创建日期：2026-09-18
- 相关 issue / ADR：[ADR-006](../docs/decisions/006-platform-governance.md)

## 背景与问题

视频、同步文本和管理员工作流分别维护执行与结果，作品查询依赖实时引擎历史，部署配置和连接设置混杂。详见当前 API 与设计文档；历史规格不作为最新行为依据。

## 目标

统一任务、项目和作品查询，保留视频历史契约。平台连接加密入库并由管理员管理；文本采用模型和篇幅固定报价、持久化队列和幂等结算。环境文件只负责部署和独立 ComfyUI 配置。

## 非目标

不新增普通用户图片生成、分镜、剪辑、成片导出或任意工作流权限；不改变管理员工作流独立连接与免平台扣费策略。

## 行为契约

- 连接版本不可变，凭据 AES-256-GCM 加密；报价绑定精确模型和连接版本，管理 API 不回显密钥。
- 文本价格按连接、模型、篇幅配置，缺价不可提交；提交原子预留额度、写任务和 outbox。保存有效版本后结算，明确失败释放，结果不明进入核对且不重复调用。
- 手动保存检查基础版本并锁定文档；AI 生成期间当前版本变化时保存候选版本，不覆盖当前版本。
- owner 验证先于任何外部调用；列表分页只返回摘要；读取不调用供应商或 ComfyUI。
- 项目组织内容，run 组织执行，work 引用版本或媒体；视频原记录保持状态事实源。
- 历史链接、队列消息和账目保持兼容；新增关系可空，不为历史任务自动建立空项目。
- ComfyUI 先登记执行意图，再提交固定 prompt ID；同步和归档在后台进行，未知提交不自动重发。

## 验收条件

- [x] 后台管理视频/文本连接、运营设置与文本价格，密钥不进入响应或日志。
- [x] 旧配置可幂等导入；最小本地/生产示例、配置检查及私有备份可用。
- [x] 视频与文本报价、受理、任务查询和恢复命令具有明确契约。
- [x] 文本并发、未知提交、版本冲突与费用边界有确定性验证。
- [x] 作品与概览统一口径，支持分页、搜索、项目及来源关系。
- [x] 工作流结果持久化，归档失败可恢复，引擎离线不影响已归档作品。
- [x] 旧数据、媒体链接和队列兼容，前端完成迁移。
- [x] 完整检查、数据库集成、Python 与 Docker 验证已执行并记录限制。

## 验证计划

运行 pnpm check:full、pnpm test:postgres、Python 节点测试和 Docker 配置/构建验证；覆盖隔离、幂等、连接版本、分页、归档与并发冲突。真实供应商不用于自动测试。

## 上线与回滚

维护窗口备份数据库与私有配置，迁移、导入后部署匹配 Web/worker。保留旧队列消费；故障关闭受理但继续读取和结算，不以旧数据库覆盖新账目。

## 实现结果

已落地连接加密与版本管理、运营设置、统一任务与作品、文本异步报价结算、项目/版本关联、工作流持久化和环境迁移。

自动及页面验证结果见 [治理验收记录](../docs/governance-verification.md)。本机已完成备份、配置导入与历史回填；真实供应商、生产存储和 GPU 部署仍需按该记录完成上线验收。
