# 工作流库与节点库切换

- 状态：completed
- 创建日期：2026-09-06

## 背景与目标

工作流页面左侧目前只展示 ComfyUI 节点，用户保存的工作流和可复用的公开工作流无法在画布入口直接找到。左侧资源面板需要在“工作流”和“节点”之间切换，并支持按范围浏览和载入。

## 行为契约

- 左侧面板提供“工作流 / 节点”主切换，节点搜索和分类行为保持不变。
- 工作流模式提供“我的工作流 / 公开工作流”范围切换，并显示数量、节点数和更新时间；拥有者自己的公开工作流同时出现在两个范围中。
- 点击工作流卡片载入画布；公开工作流可以被载入，但仍只能由当前拥有者修改原记录。
- 保存工具栏提供“私有 / 公开”切换；公开工作流会出现在其他用户的公开列表中。
- 工作流列表接口只返回当前用户自己的记录和 `public` 记录；工作流详情接口允许拥有者或公开记录的读取。
- 删除接口仍只允许拥有者删除，公开状态不改变所有权。
- 节点接口不可用时，节点模式继续显示 ComfyUI 未连接空态；工作流列表请求失败时显示页面错误信息。

## 实现结果

- `workflows.visibility` 增加 `private/public` 状态和索引。
- 工作流列表与详情服务加入公开记录读取，并返回 `scope` 用于前端分组。
- 新增左侧工作流卡片、范围切换和节点模式保留。
- 保存、打开、新建和导入工作流会同步维护公开状态。

## 验证

- 数据库迁移：`pnpm db:migrate` 已在本地开发数据库应用。
- 类型检查：`pnpm typecheck` 通过。
- 需要补充的人工检查：在浏览器中分别验证私有工作流、公开工作流、空列表和移动端布局。
