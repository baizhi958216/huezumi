# 文案、故事与短剧剧本创作 MVP

- 状态：completed
- 负责人：Codex
- 创建日期：2026-09-17
- 相关 issue / ADR：[ADR-005](../docs/decisions/005-creative-document-boundary.md)，后续总体规划见 `2026-09-16-multimodal-creative-platform.md`

## 背景与问题

平台已经有视频生成、图片工作流和任意工作流，但缺少可以被后续人物图、分镜图和镜头任务稳定引用的文本作品。只返回一段临时字符串会在用户改稿后失去来源，也无法保持人物与场景结构。

## 目标

- 提供故事、短剧剧本和营销文案三种文本创作入口。
- 复用服务端私有 OpenAI 兼容连接，支持 Chat Completions 与 Responses。
- 一次生成同时保存正文、摘要、人物设定、场景拆解和关键词。
- 生成和手动编辑都创建不可变版本，并归属到用户自己的创作项目。
- 为后续图片、视频和短剧编排提供稳定的 project、document、version 引用。

## 非目标

- 本次不接入文本生成计费、异步队列、多人协作或在线检索。
- 本次不自动触发图片、视频或连续多笔付费任务。
- 本次不实现人物设定和场景卡片的独立编辑器、分镜排序和成片导出。

## 行为契约

- 未登录用户不能读取连接、文档或提交生成。
- 连接信息只从私有 runtime config 读取；浏览器只获得连接名称和默认模型，不获得 URL 或 Key。
- `NUXT_TEXT_LLM_CONNECTIONS_JSON` 未配置时兼容复用 `NUXT_COMFYUI_LLM_CONNECTIONS_JSON`。
- `auto` 协议只在 Chat Completions 返回 404/405 时切换 Responses；鉴权、限流与服务端失败不盲目重试。
- 模型输出必须通过严格结构校验后才写入数据库；失败响应不保存半成品。
- 文档访问始终验证 owner；访问其他用户资源表现为不存在。
- 每次 AI 生成或点击“保存新版本”都新增版本，不覆盖旧版本。

## 验收条件

- [x] 创作页支持故事、短剧剧本和营销文案，并覆盖无连接、生成中、失败、成功与保存状态。
- [x] 全局导航只保留统一“创作台”入口；唯一的头部下拉提供文案剧本、视频生成和管理员图片工作流切换，页面不重复占用创作区，默认打开文案剧本。
- [x] 成功结果包含可编辑正文，以及供下游使用的人物与场景结构。
- [x] 新创作自动建立项目、文档和版本；再次生成与手动保存新增版本。
- [x] 最近文档可重新打开，刷新后仍能从 PostgreSQL 读取。
- [x] 私有连接不泄露到浏览器或错误消息，所有写入经过认证、同源与输入校验。
- [x] migration、API、当前文档和开发配置说明同步。
- [x] `pnpm check:full` 通过。

## 边界情况

连接 JSON 无效、连接无 Key、仅支持 Responses、上游返回 Markdown 围栏、上游 JSON 字段缺失、重复保存、文档与项目不匹配、访问他人文档、浏览器刷新。

## 实现结果

创作台默认 `/studio` 打开文本创作，并在内部切换 `/studio/video` 和管理员 `/studio/workflow`；同时新增文本供应商服务、项目 / 文档 / 不可变版本表与 owner 隔离 API。生成结果保留结构化人物和场景，但暂未进入现有额度系统；这一点必须在对外计费开放前补齐。
