# 百炼视频预设独立提示词节点

- 状态：completed
- 负责人：
- 创建日期：2026-09-16
- 相关 issue / ADR：[百炼 Wan 3.0 工作流](2026-09-16-bailian-wan3-comfy-workflow.md)

## 背景与问题

公开百炼预设将正向、反向提示词直接写在生成节点的两个控件中。画布没有可单独编辑、连线和替换的提示词节点，与预置的参考素材及视频输出节点不一致。

## 目标

- 公开预设默认包含正向和反向两个独立文本节点，分别连接生成节点对应输入。
- 原有默认提示词迁移到独立节点，生成节点其余参数保持原值。
- 已保存的旧五节点或四节点副本继续使用生成节点内的提示词运行。

## 非目标

- 不加入大模型改写、自动翻译或新的百炼请求字段。
- 不真实提交收费生成任务。

## 用户流程

用户从公开工作流载入预设，在左侧两个提示词节点填写文本；生成节点接收连线文本，成功视频由独立输出节点预览。反向提示词可留空。

## 行为契约

复用现有 `ForkVdoText`，输出通用 `STRING`；生成节点保留原有 `positive_prompt`、`negative_prompt` 控件和接口，连线输入覆盖内部控件值。正向提示词仍必须非空，反向提示词仍按当前 Wan 3.0 映射追加为避免约束。公开 JSON 不含密钥。

## 验收条件

- [x] Given 公开预设，When 载入画布，Then 看到两个标题明确的提示词节点，并各有一条到生成节点的连线。
- [x] Given 两节点默认文本，When 序列化运行请求，Then 正向和反向输入来自连线，模型、种子、清晰度、比例和时长不变。
- [x] Given 反向提示词为空，When 运行，Then 生成节点允许空文本；正向为空时得到原有校验错误。
- [x] Given 旧工作流，When 不存在提示词节点，Then 生成节点内的提示词仍可使用。
- [x] `pnpm check:full`、本机运行期节点定义序列化和画布人工检查通过。

## 边界情况

用户删除其中一个提示词节点或断开连线后，可回到生成节点内填写对应文本。连线存在时，生成节点内控件的文字不参与请求。

## 验证计划

- 自动化：预设节点、连线、序列化与旧图兼容。
- 人工：本机画布加载、空态和窄屏布局。
- 外部：真实百炼收费生成不在本次执行。

## 上线与回滚

更新公开预设 JSON；无需数据库迁移，旧副本继续沿用原生成节点接口。

## 实现结果

公开预设增加两个 `ForkVdoText` 节点，默认提示词从生成节点控件移到这两个节点，连线输入覆盖控件值。页面确认七节点、六连线，生成节点提示词控件显示连线优先提示；运行中的 ComfyUI `/object_info` 序列化得到七节点且没有问题。`pnpm check:full` 通过，Python mock 八项通过；窄屏和手机宽度画布已检查。真实收费生成未执行。
