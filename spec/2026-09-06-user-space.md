# 用户空间与资产管理

- 状态：accepted
- 负责人：
- 创建日期：2026-09-06
- 相关 issue / ADR：

## 背景与问题

当前额度流水在个人资料页，作品在独立的作品库页，模型资产尚无用户归属和管理入口。用户无法在一个地方了解自己的额度消耗、模型资产和近期作品；后续 Civitai 导入、用户上传和微调产物也缺少统一的数据边界。

本阶段先建立用户空间和模型资产元数据层。由于当前接入阿里云 OSS，验收不得通过真实模型上传、Civitai 下载或模型部署产生外部流量。

## 目标

- 新增 `/dashboard` 用户空间，展示额度、存储、模型资产和作品概览。
- 提供额度流水和作品的统一入口，同时保留现有 `/account` 与 `/projects` 兼容访问。
- 建立用户模型资产及多文件模型包的持久化契约，支持来源、类型、所有权、状态和大小统计。
- 模型查询始终按当前用户过滤，模型传输和部署留到后续阶段，不在本阶段触发 OSS 或 Civitai 流量。

## 非目标

- 本阶段不实现模型上传、Civitai 搜索/下载、OSS 分片传输和 GPU 主机部署。
- 本阶段不开放普通用户访问共享 ComfyUI 任意工作流。
- 本阶段不删除已有 generation 计费记录，也不改变现有作品库查询契约。

## 用户流程

1. 登录用户从顶部帐号菜单或主导航进入“我的空间”。
2. 概览显示可用额度、预留额度、本月/累计消耗、作品数量、模型数量和存储用量。
3. 用户切换“额度明细”“我的模型”“我的作品”查看对应列表。
4. 额度明细使用当前用户的不可变流水；作品列表复用现有 generation 查询；模型列表展示当前用户已经登记的模型资产。
5. 没有模型时显示空状态，并明确说明真实模型传输尚未启用，不产生 OSS 流量。

## 行为契约

### 用户空间

`GET /api/account/overview` 返回当前用户的额度汇总、存储汇总、作品统计、最近额度流水、最近作品和最近模型资产。服务端使用 session owner 查询，不接受客户端传入 owner ID。

额度定义：

- `available = balance - reserved`
- `totalSpent` 和 `monthSpent` 只累计 `ledger_entries.type = charge` 且金额为负的实际结算记录。
- 预留、释放和管理员调整保留在流水中，但不被误计为生成消耗。

### 模型资产

`model_assets` 保存模型资产元数据，`model_asset_files` 支持一个资产包含多个文件。模型资产包含：

- owner、名称、类型、来源、来源引用、基础模型、触发词和说明；
- private/shared/platform 可见性；
- pending/ready/failed/quarantined 状态；
- 总大小、SHA256、创建和更新时间。

`GET /api/models` 只返回当前用户未软删除的模型资产，不返回对象存储 key、密钥或运行时文件路径。

模型来源预留为 `upload`、`civitai`、`training`、`platform`；模型类型预留 Checkpoint、LoRA、VAE、CLIP、UNet、ControlNet、Embedding、放大模型和其他。

### 兼容性与权限

- `/account` 继续用于个人资料、头像和密码；`/projects` 继续用于完整作品库。
- 现有 `generations` 仍是任务和计费事实源，本阶段不迁移其存储结构。
- 未登录访问用户空间和模型列表返回 401；用户不能通过修改 URL 读取其他用户模型。
- 模型资产的真实文件传输、部署、卸载和删除必须在后续任务中增加独立状态机与清理策略，不能由本阶段的只读列表接口隐式执行。

## 验收条件

- [ ] Given 已登录用户，When 从导航进入 `/dashboard`，Then 能看到概览卡片、额度流水、模型资产和作品入口。
- [ ] Given 没有模型资产，When 打开“我的模型”，Then 显示空状态且不触发 OSS/Civitai 请求。
- [ ] Given 用户存在模型资产，When 打开“我的模型”，Then 只显示该用户自己的资产、类型、来源、状态和大小。
- [ ] Given 用户存在额度流水，When 查看“额度明细”，Then 本月消耗与实际 charge 结算一致，release 不会重复计费。
- [ ] Given 用户存在作品，When 查看“我的作品”，Then 显示现有 generation 状态、模型、时间和扣费，并可进入作品库。
- [ ] Given 未登录或伪造 owner ID，When 请求用户空间或模型列表，Then 返回 401 或不返回其他用户数据。
- [ ] Given 阿里云 OSS 已配置，When 执行本阶段自动化检查和人工页面检查，Then 不上传、下载或删除模型文件。
- [ ] Given 移动端窄屏，When 打开用户空间，Then 卡片和列表可纵向阅读，导航可换行。

## 边界情况

- 钱包不存在时余额按 0 展示；额度汇总不因空流水报错。
- 没有作品、流水或模型时分别显示空状态。
- 模型文件大小为空时按模型资产总大小展示，不猜测运行时目录大小。
- 已软删除模型不出现在用户列表和存储汇总中。
- generation 的供应商错误不进入用户空间的服务端堆栈响应。

## 实现提示

- 模型原文件后续应进入独立的模型资产存储/部署流程，不复用普通图片上传接口。
- 共享 ComfyUI 的私有模型需要后续通过 `modelAssetId` 绑定和服务端所有权校验，不能仅信任节点中的文件名。
- 多文件模型包已经在表结构中预留，后续视频模型可以同时部署 diffusion model、VAE 和文本编码器。

## 验证计划

- 自动化检查：`pnpm check:full`，覆盖迁移生成、类型、API 契约和构建。
- 人工检查：登录/未登录、空状态、带流水/作品的页面、移动端布局和用户菜单入口。
- 明确不执行：真实 OSS 模型上传、Civitai 下载、模型部署和模型删除。

## 上线与回滚

- 新增数据库 migration；应用回滚时保留新增表，不影响已有帐号、作品和额度。
- `/dashboard` 是新增入口，删除页面和相关只读接口不会改变现有 `/account`、`/projects` 行为。
- 模型文件传输未在本阶段启用，不新增 OSS 权限范围或新的外部下载域名。

## 实现结果

进行中：已完成用户空间页面、额度汇总接口、模型资产元数据表和当前用户模型只读列表接口；模型真实传输与部署仍按非目标保留。
