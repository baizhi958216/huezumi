# 百炼 Wan 3.0 多模态参考视频工作流

- 状态：completed
- 负责人：
- 创建日期：2026-09-16
- 相关 issue / ADR：

## 背景与问题

工作流库已有 MiniMax H3 本地多素材预设，运行依赖本地权重。百炼 Wan 3.0 All-in-One 已由平台供应商适配器接入，但 ComfyUI 画布没有可直接载入的 API 工作流。

## 目标

- 新增默认采用全模态参考的百炼视频预设，预置参考图、参考视频、参考音频节点。
- 支持正向和反向提示词、随机种子、模型、清晰度、比例、时长，以及音频、提示词改写、水印等高级参数。
- 三类素材均可选：节点为空、断开或删除时不传入对应 `media`；所有素材为空时按文生视频提交。
- 异步轮询任务，将生成视频保存为 ComfyUI 可预览输出。

## 非目标

- 不改变平台生成请求、报价和任务存储契约，不在工作流 JSON 中保存百炼 API Key。
- 不支持首尾帧、视频编辑/延长、文件/网页素材，也不提供普通用户执行任意 ComfyUI 工作流的权限。
- 不执行带真实凭据的收费生成验收。

## 用户流程

1. 管理员载入“阿里云百炼 · Wan 3.0 多模态参考”预设。
2. 配置执行端私有百炼 API Key、业务空间和地域；在画布中填写提示词与参数，可上传任意参考素材。
3. 运行后先上传已选素材，再创建百炼异步任务并轮询。成功时在右侧预览视频；配置、素材、提交、超时和上游失败显示可操作错误。

## 行为契约

- 仅支持 `wan3.0-video` 和 `wan3.0-video-prime`，默认高速版；接口、模型、Key 必须属于同一地域。
- 素材按参考图、视频、音频顺序组成 `input.media`；每类素材按类型分别编号。空文件槽不上传、不进入请求。参考图最多 10 张、视频和音频各最多 5 段；本预设每类各一槽。
- `duration` 可为 -1 智能时长或 2–30 秒整数；有参考视频时需遵守“输入总时长 + 输出时长 ≤30 秒”的供应商限制。
- Wan 3.0 API 未声明独立 `negative_prompt`；画布中的反向提示词追加为正向提示词里的“避免出现”约束，效果由模型理解决定。
- 素材从 ComfyUI input 目录读取并上传到百炼模型绑定的临时 OSS；HTTP 请求携带 `X-DashScope-OssResourceResolve: enable`。结果在 ComfyUI output 目录留存，百炼任务 ID 和结果 URL 只在上游有效 24 小时。
- 画布执行沿用管理员权限。执行进程读取私有环境配置，节点定义、工作流 JSON、浏览器响应及错误不包含密钥。

## 验收条件

- [x] Given 内置预设，When 载入画布，Then 能编辑提示词和全部参数，三个参考素材节点默认出现并连接。
- [x] Given 空素材节点，When 序列化并运行，Then 不要求上传文件，也不下发 `media`。
- [x] Given 任意一类或三类素材，When 运行，Then 只上传非空文件，并按 Wan 3.0 的类型构造 `media`。
- [x] Given 成功任务，When 百炼返回视频链接，Then 保存为 ComfyUI 输出并在右侧显示（以 mock 验证文件输出协议；真实收费任务待凭据验收）。
- [x] Given 缺少配置、无效参数、上传/提交/轮询失败或超时，When 运行，Then 显示脱敏、可操作错误。
- [x] Given 已保存的旧工作流，When 新预设上线，Then 旧图保持可读，工作流库自动发现新增条目。

## 边界情况

参考视频和音频的编码、帧率、长度、尺寸以及总时长由百炼进行最终校验；本地检查文件格式和大小。异步任务提交成功后，断网或超时不自动创建第二个任务。再次手动运行可能产生新的收费任务。

## 验证计划

- 自动化：Python mock 验证空素材、组合、上传、状态和脱敏；工作流 JSON 结构与序列化；`pnpm check:full`。
- 人工：画布载入、空态、上传、右侧预览和窄屏布局。
- 真实收费调用需用户凭据和主动执行。

## 上线与回滚

部署 ComfyUI 项目节点包及私有环境配置，无数据库迁移。回滚可移除预设与节点，用户保存的旧图仍保留但显示缺失节点。

## 实现结果

已实现项目节点、内置预设和执行端环境注入；本地 ComfyUI 重启后 `/object_info` 返回 4 个新节点。页面载入确认 4 节点、3 连线、上传入口和全部默认参数。Python mock 测试 6 项与原节点测试 26 项通过；使用运行期节点定义序列化预设无问题；`pnpm check:full`、Compose 配置校验通过。未执行真实百炼收费生成，也未构建生产 GPU Docker 镜像。
