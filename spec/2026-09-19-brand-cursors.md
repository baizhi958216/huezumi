# 绘小宙自定义鼠标指针

- 状态：completed
- 负责人：Codex
- 创建日期：2026-09-19
- 相关 issue / ADR：无

## 背景与目标

用户要求用 imagegen 生成图片并接入自定义鼠标指针，延续奶油白、珊瑚与鹅黄品牌，不使用蓝紫色。

## 非目标

不增加鼠标追踪脚本、尾迹、动画或改变点击行为，不更改业务接口。

## 用户流程与行为契约

- 精细鼠标且支持悬停时，普通区域显示星星箭头，链接、按钮等可点击控件显示星球手形。
- 图片使用透明 PNG，40×40，热点分别为 (6, 4) 和 (17, 5)，文件不可用时回退 auto/pointer。
- 文本输入保留 text，禁用控件保留 not-allowed，拖拽与缩放不覆盖其专用光标。
- 触屏和强制颜色模式不启用自定义图片；键盘导航、焦点和点击目标不受影响。

## 验收条件

- [x] 两张资源透明、尺寸正确，可通过静态路径访问。
- [x] 普通、可点击、文本及禁用状态显示正确 CSS cursor。
- [x] 桌面交互与移动布局保持正常。
- [x] pnpm check 通过。

## 边界情况

系统及浏览器可限制或覆盖自定义光标；图片加载失败时使用原生后备，不隐藏光标。

## 验证计划

检查图片尺寸/alpha、浏览器计算样式与真实控件点击，执行 pnpm check。不请求真实生成供应商。

## 上线与回滚

无迁移。移除相应 CSS 与两张静态图片即可恢复原生指针。

## 实现结果

已生成并接入两张 40×40 透明 PNG。浏览器计算样式验证普通区域、链接、按钮、登录输入框与禁用报价按钮分别使用预期 cursor；登录打开关闭与路由点击正常。触屏与强制颜色模式由媒体查询排除，未在实体触屏或强制颜色环境中人工验证。PNG alpha 和尺寸通过 sips 检查；pnpm check 结果见交付说明。完整 imagegen 提示词存于 docs/brand-art.md。
