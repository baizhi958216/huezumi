# 工作流作品卡片弹窗预览

- 状态：completed
- 负责人：
- 创建日期：2026-09-16
- 相关 issue / ADR：[工作流视频进入作品库](2026-09-16-workflow-outputs-projects.md)

## 背景与问题

作品库已能列出百炼工作流视频，但卡片上直接放了带播放控件的小视频。用户希望点开作品卡片后在弹窗中播放，和作品库的卡片详情交互一致。

## 目标

- 工作流卡片只展示视频封面、播放提示和作品摘要，不在卡片内播放。
- 点击卡片打开大尺寸弹窗，弹窗内提供可播放视频和原文件入口。
- 关闭弹窗时停止播放；键盘与移动端均可打开和关闭。

## 非目标

- 不改变工作流执行、文件存储、作品库 API 或平台生成作品的详情弹窗。

## 用户流程

管理员在作品库找到工作流作品，点击卡片，弹窗中播放视频；关闭后返回作品库原位置。

## 行为契约

卡片按钮是弹窗唯一入口；封面视频静音、无控件且不自动播放。弹窗只在打开时载入播放器，关闭即卸载；加载失败显示可操作提示和原视频链接。弹窗沿用管理员鉴权的视频 URL，不暴露文件系统路径。

## 验收条件

- [x] Given 工作流作品，When 查看卡片，Then 卡片无视频播放控件并有清楚的可点击提示。
- [x] Given 点击或按 Enter 打开卡片，When 弹窗出现，Then 可在大播放器中观看，原视频入口可用。
- [x] Given 视频播放中，When 关闭弹窗，Then 播放停止，再次打开从开头开始。
- [x] Given 视频加载失败，When 弹窗打开，Then 显示错误状态和打开原文件入口。
- [x] 窄屏布局、`pnpm check` 和人工页面验证通过。

## 边界情况

ComfyUI 关闭或输出文件被清理时，弹窗播放器无法加载；此变化不重新生成或提交收费任务。

## 验证计划

- 页面：卡片、弹窗、播放、关闭、键盘和手机宽度。
- 工程：`pnpm check`，既有作品库数据测试继续通过。

## 上线与回滚

只替换前端作品卡片，保留现有作品库查询；回滚到原卡片即可。

## 实现结果

工作流作品卡片展示静音封面和打开提示；点击或按 Enter 打开大播放器弹窗，关闭时停止播放并复位。播放器错误时显示重试提示与原文件链接。实际百炼作品在桌面和 390px 宽度页面可打开弹窗；视频可播放，关闭后再次打开从 0 秒开始。`pnpm check` 通过。
