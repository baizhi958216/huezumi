# 作品库（Projects）界面与检视体验重构

- 状态：completed
- 负责人：forkvdo 核心开发
- 创建日期：2026-09-04
- 相关 issue / ADR：

## 背景与问题

现有作品库（`app/pages/projects.vue`）存在严重影响使用体验的问题：

1. **画幅硬编码裁剪**：卡片容器写死 `aspect-video`（16:9）且视频元素使用 `object-cover`，导致主流的 9:16 竖屏或 1:1 正方形视频的画面上下部分被严重裁切，用户无法正常观看视频完整内容。
2. **生成上下文与素材缺失**：仅用两行文本截断展示提示词，无法查看长提示词或反向提示词；生成请求绑定的 `media: MediaInput[]`（原始参考图、首尾帧、参考视频、参考音频）完全未在界面中展示，用户无法追溯视频的输入来源。
3. **浏览效率与交互低**：卡片固定 3 列大卡片排布，无列表/密集视图切换；不支持关键词搜索、比例筛选、平台模型过滤与素材类型过滤；进行中任务缺少自动轮询，必须手动反复刷新。

## 目标

- 消除横竖屏裁切，卡片自适应比例，并提供电影级大屏剧场检视器，无损呈现 9:16 竖屏、16:9 横屏、1:1 等任意画幅。
- 完整展示正向提示词（带一键复制）、反向提示词、规格参数，并可视化呈现所有原始参考素材（图片预览放大、视频微播放器、音频试听）。
- 提供多维过滤（状态、比例、供应商、素材类型）、实时搜索防抖、画幅自适应网格与紧凑列表双视图切换，以及进行中任务自动轮询。
- 提供“在创作台中复用此任务”能力，一键回填参数与参考素材。

## 非目标

- 不修改后端存储结构或 `GenerationRecord` / `GenerationRequest` 领域契约（已有字段已完全包含所需数据）。
- 不破坏现有 OSS 归档和临时链接转存流程。

## 用户流程

1. 用户进入 `/projects`，看到顶部动态统计卡片（全部/进行中/已完成/失败/OSS已归档）和筛选工具栏。
2. 用户可输入关键词实时搜索，或点击“竖屏”筛选仅查看竖屏生成结果，或切换为“紧凑列表”视图快速浏览历史。
3. 用户悬停卡片可自动静音预览播放视频；点击卡片打开剧场检视弹窗。
4. 在检视弹窗中，用户查看完整未裁剪的视频（支持倍速、循环、全屏、下载），查看完整长提示词与反向提示词，浏览并放大原参考图或试听原参考音频。
5. 用户可点击“在创作台中复用”，自动带着该任务的所有参数与素材跳转至 `/studio` 继续创作。

## 行为契约

- 遵循 `shared/types/generation.ts` 的 `GenerationRecord` 与 `MediaInput` 规范。
- 视频比例自适应：优先取 `record.ratio`，加载后以视频真实像素尺寸（`videoWidth / videoHeight`）精确贴合。
- 任务刷新遵循 AGENTS.md：仅对 `PENDING`/`RUNNING` 执行刷新；终态任务不主动轮询。

## 验收条件

- [x] 9:16 竖屏视频在卡片中不被上下裁切，在剧场检视弹窗中居中完整呈现。
- [x] 16:9 横屏视频在卡片与弹窗中比例正常。
- [x] 带有参考素材的任务能清晰展示素材列表，支持放大预览参考图、试听音频、播放参考视频。
- [x] 提示词完整可展开并支持一键复制（带复制成功提示）。
- [x] 支持关键词检索、状态筛选、画幅筛选、供应商筛选与视图切换。
- [x] “在创作台中复用”能正确回填所有参数与素材至创作台。
- [x] `pnpm check` 与 `pnpm check:full` 均通过。

## 验证计划

- 自动化检查：`pnpm check`，`pnpm check:full`
- 人工检查：在浏览器中检查竖屏记录（如 `wan3` 9:16 视频）、横屏记录、纯文本记录、多模态参考记录的展示与播放效果。

## 实现结果

- 重构 `app/pages/projects.vue`，实现指标统计快速筛选栏、多维检索过滤工具栏、画幅自适应网格与紧凑列表双视图切换，以及进行中任务自动轮询。
- 新增 `app/components/generation/GenerationCard.vue`，根据视频画幅（竖屏/横屏/方形）自适应容器尺寸，杜绝黑边与裁切，支持悬停静音播放与素材数量角标。
- 新增 `app/components/generation/GenerationDetailModal.vue`，实现剧场级全画幅无损视频播放器（支持倍速、循环、全屏、左右方向键切换作品），并提供完整正反向提示词复制、原始参考素材画廊（支持放大、播放、试听）及技术参数检视。
- 新增 `app/components/generation/MediaPreviewModal.vue`，支持参考图放大灯箱、参考视频微播放器与参考音频独立试听。
- 在 `app/pages/studio.vue` 中支持 `route.query.from` 参数读取，实现作品库到创作台的一键参数与素材复用闭环。
- `pnpm check` 与 `pnpm check:full` 全部通过。
