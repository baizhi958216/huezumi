# 首页其余区域延续插画参考

- 状态：completed
- 负责人：Codex
- 创建日期：2026-09-19

## 背景与目标

用户要求其余部分同样遵循已确认的插画首屏方向。创作入口、画廊、流程、模型目录、FAQ 与结尾采用相同的纸张、柔和配色、贴签和留白语言。

## 非目标与行为契约

不改变 API、模型能力、权限或生成流程。供应商与模型仍由目录驱动，加载、空态与重试保留。图片工作流仍仅向管理员开放。

## 用户流程

浏览创作方向、示意画廊和步骤，选择模型或展开常见问题，进入现有创作台。

## 验收条件

- [x] 所有首页章节视觉与首屏一致，各章节保留不同排版节奏。
- [x] 供应商切换、模型选择、FAQ 可交互，状态与权限说明清晰。
- [x] 桌面与手机浅深主题不溢出，装饰不拦截操作。
- [x] pnpm check 通过。

## 边界情况与验证计划

长模型 ID 可换行；窄屏取消画廊错位，减少动态偏好保持支持。浏览器检查首页各模块与主要交互，不调用真实生成服务。

## 上线与回滚

纯呈现改动，无迁移；回滚组件和样式即可。

## 实现结果

已完成淡彩创作入口、白边画廊、旅行路线、模型工具箱、问答和插画结尾。桌面各章节、390px 窄屏浅深色已检查，页面宽度 390px 无横向溢出。供应商切换、模型选择及目标链接、FAQ 展开已验证。pnpm check 通过（54 项测试通过，22 项依现有配置跳过）。加载与失败分支保留，但未在浏览器注入故障模拟；未调用真实供应商。
