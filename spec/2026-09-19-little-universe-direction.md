# 全站小宇宙视觉与语气

- 状态：completed
- 负责人：Codex
- 创建日期：2026-09-19
- 相关 issue / ADR：无

## 背景与问题

用户明确要求全站往轻快、可爱、有二次元感的方向发展，以创作自己的小宇宙为主题。现有首页偏影视生产工具的表述，与暖色插画及创作台语气不一致。本规格记录新的设计方向，不改写此前已完成规格。

## 目标

- 首页以故事、角色、画面、视频为创作主线；文案亲切、具体。
- 全站复用暖奶油底色、珊瑚强调色、圆润控件和柔和边框；首页采用插画手帐与开放式排版。
- 品牌表达与实际能力一致，明确图片工作流的管理员限制。

## 非目标

不新增角色一致性能力、图片权限、生成服务或数据结构，不改变导航及计费流程。不添加外部依赖或新图片。

## 用户流程

用户从首页选择创作方向，进入既有故事或视频创作台；管理员可进入图片工作流。生成、保存及失败重试仍按现有流程执行。

## 行为契约

只调整视觉与呈现文案。模型目录仍由 API 驱动，加载、空态和错误处理不变。已有作品及用户输入保持兼容。

## 验收条件

- [x] 首页主标题与四个入口清楚表达小宇宙创作方向。
- [x] 示例插画标明 AI 概念用途，不冒充真实生成结果或实时录制。
- [x] 共享按钮、卡片、导航与主题变量统一，不更改权限或功能。
- [x] 手机、桌面与深色模式可读，无明显布局溢出，减少动态偏好受尊重。
- [x] 创作台空态、作品库未登录错误提示可辨识，pnpm check 通过。

## 边界情况

移动端插画说明放在画面下面，避免遮挡；深色主题使用语义色；创作页不添加干扰输入的装饰动画。

## 验证计划

运行 pnpm check；浏览器检查首页、创作台、作品库，检查导航、灵感切换、主题与窄屏。真实供应商生成不属于此次验证。

## 上线与回滚

无迁移或新配置，回滚本次样式与文案即可。

## 实现结果

已更新首页全模块的主线文案、共享主题与控件，以及作品库和个人空间文案。桌面首页、390px 首页及深色创作台已人工检查，灵感切换正常。修复检查中发现的作品库空值选项导致客户端 500：仅在视图层使用非空选项值，API 仍省略全部项目筛选。未登录状态验证通过；未模拟模型目录加载失败，未验证登录后的作品或管理员页面，未调用真实供应商。pnpm check 包含 54 个通过、22 个按现有配置跳过的测试，lint 与类型检查通过。
