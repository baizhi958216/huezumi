# 首页开放式版面

- 状态：completed
- 创建日期：2026-09-19
- 负责人：Codex

## 背景与目标

用户反馈通篇卡片导致缺少设计感。首页改用开放排版、插画画廊、编号步骤、下划线选项和细分隔线建立层次，减少重复圆角面板与阴影，保留暖色品牌。

## 非目标

不修改生成、权限、计费或模型能力；创作台功能表单仍按需要分组。不增加图片和依赖。

## 用户流程与行为契约

首页顺序为品牌首屏、灵感选择、创作方向、题材画廊、创作步骤、模型目录、问答与创作邀请。已有链接、模型切换、灵感选择和问答键盘交互继续有效。示例图片仍标明 AI 生成，图片工作流权限说明保留。

## 验收条件

- [x] 创作方向、画廊、步骤、模型和问答不再使用重复卡片外框。
- [x] 桌面具有不同版式节奏，手机单列无溢出，深色主题清楚。
- [x] 模型目录、灵感与问答交互可用。
- [x] pnpm check 通过。

## 边界情况与验证

保留模型加载/空/失败状态；图像具备替代文本；降低动态效果偏好仍生效。人工检查桌面、手机与深色，不提交生成任务。

## 上线与回滚

仅前端布局和样式，无迁移，回滚本次相关文件即可。
