# 从工作流视频读取原始画布

- 状态：completed
- 负责人：
- 创建日期：2026-09-16
- 相关 issue / ADR：[工作流视频进入作品库](2026-09-16-workflow-outputs-projects.md)

## 背景与问题

作品库能播放管理员的工作流视频，但作品详情没有生成时画布的入口。当前百炼视频对应的 ComfyUI 历史含 `extra_pnginfo.workflow` 快照，原保存工作流可能已经被修改或删除。

## 目标

- 对有执行快照的工作流作品显示“查看原始工作流”，打开编辑器并还原当时节点、连线和控件值。
- 仅当前执行 owner 的管理员能读取快照；作品列表只返回可用性，不返回画布内容或私有连接值。
- 历史缺失、快照无效或 ComfyUI 不可用时给出明确错误，不打开错误的同名工作流。

## 非目标

- 不把快照保存成新工作流，不重新生成视频，不更改执行或作品的存储格式。
- 不把 ComfyUI 历史当成长期归档；历史删除后仍无法恢复快照。

## 用户流程

管理员打开作品库的工作流视频卡片，在播放弹窗点“查看原始工作流”；新页面加载本次执行的画布快照，必要时可自行保存为私有副本。

## 行为契约

作品视图从 owner 所属的成功执行历史判断是否有结构有效的工作流图，只增加布尔可用性。编辑器用执行 ID 调用已有 owner 鉴权的历史 API，提取 `extra_pnginfo.workflow`，导入图时不继承原保存工作流 ID，默认私有。执行 ID URL 参数必须验证；工作流图不是完整快照时不展示入口。

## 验收条件

- [x] Given 含工作流快照的已完成视频，When 打开作品弹窗，Then 出现原始工作流入口；点击后编辑器显示该执行的节点与连线。
- [x] Given 快照对应已更改或不存在的保存工作流，When 打开原始工作流，Then 仍显示历史快照且保存时默认创建私有副本。
- [x] Given 无快照或结构无效的历史，When 查看作品，Then 不展示原始工作流入口。
- [x] Given 非 owner、普通用户或无效执行 ID，When 请求历史快照，Then 现有鉴权与校验拒绝读取。
- [x] 加载失败有明确提示；窄屏入口可操作；`pnpm check:full` 与实际百炼作品页面验证通过。

## 边界情况

ComfyUI 历史和节点定义必须可访问。缺失节点仍由编辑器现有占位卡片展示；快照可能携带私有连接，只有执行 owner 的管理员可打开，不进入公开工作流或作品列表响应。

## 验证计划

- 单元验证工作流快照有效性与缺失历史的作品映射。
- 本机作品弹窗到编辑器验证实际百炼快照；验证加载、错误和手机宽度。
- 运行 `pnpm check:full`。

## 上线与回滚

复用既有历史 API 与工作流导入路径；移除入口和 URL 快照加载即可回滚，不需要迁移。

## 实现结果

作品视图增加快照可用性标记，弹窗展示“查看原始工作流”入口。编辑器从所属执行历史导入原始图，默认按未保存的私有工作流处理。实际百炼视频从作品库打开后显示 7 个节点、6 条连线和执行时提示词；390px 宽度弹窗可操作，无效执行 ID 显示错误。测试覆盖有效、缺失和无效快照；`pnpm check:full` 五项通过。仍依赖 ComfyUI 保存历史，未做长期归档。
