# 主题切换从指针位置扩散

- 状态：completed
- 负责人：
- 创建日期：2026-09-15
- 相关 issue / ADR：

## 背景与问题

全站头部的主题按钮已有圆形 View Transition，但扩散起点只依赖按钮转发的 click 坐标；包装组件未传递原始指针坐标时，动画可能从按钮中心或视口中心开始。

## 目标

- 鼠标或触控点击主题按钮时，新主题从实际按下位置向四角扩散。
- 键盘操作与减少动态效果设置继续正常切换主题。

## 非目标

- 不改变主题持久化方式或其他页面交互。

## 用户流程与行为契约

用户按下全站头部的主题按钮，记录相对视口的指针位置；点击完成后，用该位置作为新主题圆形裁剪动画的圆心。键盘触发时从按钮中心展开。浏览器不支持 View Transitions 或用户偏好减少动态效果时直接切换。

## 验收条件

- [x] Given 鼠标在主题按钮边缘按下，When 切换主题，Then 圆形扩散从该按下位置开始，而非按钮中心。
- [x] Given 键盘触发主题按钮，When 切换主题，Then 主题切换成功，动画从按钮中心开始。
- [x] Given 减少动态效果或不支持 View Transitions，When 切换主题，Then 主题立即切换。
- [x] Given 窄屏布局，When 点击主题按钮，Then 扩散仍覆盖整个视口。

## 边界情况

连续点击期间已有动画时忽略重复切换；动画失败时保留新主题。指针位置只用于紧接着的切换，不在后续键盘操作中复用。

## 验证计划与实现结果

实现通过按钮的 pointerdown 捕获指针坐标，并在 click 中消费；原有 View Transition 的裁剪动画及主题偏好保持不变。运行 `pnpm check`，人工检查桌面、窄屏、键盘及减少动态效果偏好。

## 上线与回滚

无配置或数据迁移；回滚头部按钮和主题 composable 即可。
