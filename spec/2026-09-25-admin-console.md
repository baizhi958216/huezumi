# 控制面板功能重组

状态：implemented。日期：2026-09-25。

## 问题与范围

旧控制面板将用户、视频价格、视频异常和审计混在总览，将文本/图片价格及异常塞进设置页；注册策略与用途分配必须一并保存。任务列表缺少文案/图片正常记录，近期条数限制还可能隐藏旧异常。

本次按管理任务拆分导航与页面，复用原服务及结算合同。不调整数据库结构，不迁移账户或媒体，不接入新供应商，不改变付费任务受理流程。

## 页面合同

- `/admin`：用户与创作任务统计、待核对数量、尚未分配的创作用途、常用操作入口。
- `/admin/services`：用途逐项分配/移除，统一连接与版本管理。撤销版本放在历史版本内。
- `/admin/pricing`：文本/图片/视频分组，默认展示每组最新版本、可查看历史；视频档位逐行填写，版本自动递增。
- `/admin/tasks`：全部类型任务与待核对视图，数据库搜索及每页 30 条；视频去除 runs 镜像。同步状态、释放预留、人工结算为独立操作。
- `/admin/users`：账户搜索分页、角色/存储限额、启停和有原因的额度调整。
- `/admin/settings`：仅注册、赠送额度、活动任务上限、平台预算及只读部署配置。
- `/admin/audit`：最近操作检索与可展开详情；邀请码独立入口保留。

## 接口与数据

增加 `GET /api/admin/tasks` 与 `PATCH /api/admin/settings`。任务查询返回受控字段，不返回凭据。视频任务仅从 generations 读取，其他类型从 runs 读取。设置 PATCH 在事务锁内合并，只校验修改的用途；省略保留，null 移除连接。PUT 保留原完整替换行为，并共用事务锁。

用户接口增加服务端 q/page，省略分页参数仍保持旧数组上限。总览新增跨模态计数，旧视频统计字段保持兼容。完整参数见 [API](../docs/api.md)。

## 权限、异常与恢复

所有管理接口要求管理员。前端隐藏不替代鉴权。释放/结算沿用原幂等账本与预留上限，不直接写余额。未确认外部结果不重复生成；结算表单必须输入核对依据，提交时禁用重复操作，错误保留草稿。局部设置保存不覆盖无关字段，已失效的旧分配不阻止改运营参数。

## 验收及限制

- 单元验证局部保存保留未修改值、移除分配及非法输入。
- 隔离 PostgreSQL 验证任务跨表去重、筛选/分页及并发设置更新，纳入 `pnpm test:postgres`。
- 执行常规测试、lint、typecheck、构建；浏览器使用模拟数据检查页面、结算原因约束和窄屏布局。
- 模拟数据浏览器检查不等于真实供应商或真实账户验收。未执行收费生成。
- 价格最新版本按精确键展示；最终报价仍由既有服务匹配通配规则。审计保留最近 200 条窗口，未增加全量审计导出。
