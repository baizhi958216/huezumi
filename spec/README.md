## 生命周期

采用 `draft → ready → implementing → implemented`，被后续规格取代时标记 `superseded` 并链接替代文件。`implemented` 表示对应代码存在，不能替代每项验收证据；没有执行的检查写“未运行”，不要勾选通过。

文件命名为 `YYYY-MM-DD-short-name.md`。重大跨模块决策另外记录 [ADR](../docs/decisions/README.md)。落地后同步 README、DESIGN 与相关 docs；操作手册不复制完整规格。简单文案修正无需新建规格。

新规格至少写清问题、范围与非目标、接口/数据变化、权限/计费、异常与恢复、迁移影响、验收方法和已知限制。基于源码补录时明确日期及证据范围，不倒填旧验收日期。
