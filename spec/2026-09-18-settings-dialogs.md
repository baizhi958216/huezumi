# 设置表单按需弹窗展示

- 状态：completed
- 负责人：Codex
- 创建日期：2026-09-18
- 相关 issue / ADR：无

## 背景与问题

创作台已采用参数弹窗，但帐号资料、管理员连接、运营设置和价格发布仍把完整表单常驻页面，挤占状态与内容列表。

## 目标

- 页面保留状态摘要与明确入口，低频编辑在弹窗内完成。
- 草稿与已保存数据分离，取消后重开恢复已保存值，失败保留输入。

## 非目标

- 不修改 API、权限、存储、计费或创作台已有参数行为。
- 不将核心内容列表、任务核对和审计记录移入弹窗。

## 用户流程

1. 从帐号页的「编辑资料」、后台连接的「新建连接 / 编辑」、运营设置的「编辑设置」、价格列表的「发布价格」或用户列表的「调整额度」打开弹窗。
2. 编辑并提交，提交期间显示忙碌状态，禁止重复提交与关闭。
3. 成功关闭并更新摘要；失败在弹窗内显示错误；取消、关闭或 Escape 丢弃本轮草稿。
4. 连接历史版本、部署状态通过按需查看弹窗展示。

## 行为契约

- 沿用 Nuxt UI Modal 的焦点管理、键盘关闭和可访问标题。
- 敏感凭据不回显，关闭连接弹窗清空临时密钥；上传头像仍沿用先上传、保存后绑定的生命周期。
- 运营设置编辑使用副本，关闭不修改当前摘要。每次新建连接完整重置默认字段。
- 价格发布保持显式提交，成功才更新列表；草稿不会自动保存。
- 页面内容隔离堆叠上下文，固定导航不遮挡弹窗及其下拉菜单；标题区域为关闭按钮留出空间。

## 验收条件

- [x] 帐号页和管理后台首屏不常驻低频配置表单，空列表显示操作入口。
- [x] 资料、连接、运营设置、文本及视频价格弹窗可打开、取消和重开，草稿不污染摘要。
- [x] 提交成功关闭并反馈，失败保留输入且错误可见，进行中阻止重复提交与关闭。
- [x] 连接历史和部署状态可按需查看，窄屏弹窗可滚动且控件不横向溢出，键盘可关闭并返回入口。
- [x] 原有 API、权限和历史记录契约保持兼容。

## 边界情况

- 加载失败显示错误与重试入口，不伪装成空列表。
- 上传成功但取消资料编辑时，未绑定素材沿用现有资产生命周期。
- 提交成功而列表刷新失败时，不鼓励重复发布；已保存结果仍应反馈。

## 实现提示

复用现有 UModal 和表单字段，不引入依赖。

## 验证计划

- 自动化检查：pnpm check。
- 人工检查：帐号页与两处管理员页面，桌面及窄屏弹窗、取消重开、加载/空/失败状态；使用本地 mock 验证提交，不修改真实价格或连接。
- 需要凭据或外部环境的检查：真实持久化和供应商调用不属于本次 UI 改动。

## 上线与回滚

无需迁移和环境变量，回滚对应前端页面即可。

## 实现结果

已将帐号资料、模型连接、运营设置、文本/视频价格与用户额度调整移入按需打开的弹窗，历史版本和部署状态通过独立弹窗查看。新增草稿隔离、表单忙碌保护、局部错误及成功反馈；修复固定导航遮挡弹窗、窄屏标题与关闭按钮重叠的问题。

验证使用临时本地代理返回模拟 API 数据，不读写真实帐号、连接、价格或账目。人工验证覆盖桌面、390×844 与 320×640 窄屏、字段回填、取消重开、Escape 与焦点返回、长表单滚动和下拉菜单、失败保留草稿、成功更新摘要、重复提交保护，以及连接空态、加载失败与重试。临时预览已清理。

`pnpm check` 通过（42 项测试通过，22 项数据库集成测试按默认入口跳过，文档约束、lint 与类型检查通过）。本次不改持久化契约，未执行真实供应商调用、头像上传或生产配置变更。
